# План работ (черновик к обсуждению)

Цель v1.0 — «около-готовая» версия: весь DESIGN.md, кроме открытых вопросов, EN + RU, настройки.
Каждый этап — рабочий мод, который грузится без ошибок; проверка в игре после каждого.

## Этап 0. Каркас
- `About/About.xml` (packageId `bebra.paramedic`, 1.6, зависимость Harmony), `Preview.png`, `LoadFolders.xml`.
- `Source/Paramedic.csproj` (net472, ссылки на `Assembly-CSharp`, `UnityEngine.*`, `0Harmony` из мастерской).
- Сверка API 1.6 декомпиляцией (`ilspycmd`) — список нужных классов и сигнатур в `docs/API.md`.

## Этап 1. Форма (только XML + текстуры)
- 8 `ThingDef` одежды: рубашка, штаны, жилет, куртка, берет, каска, очки (`MayRequire` Ideology), разгрузка.
- 3 `ResearchProjectDef`, рецепты через `recipeMaker`, цены/материалы из §2.1.
- Без кода роль ещё не работает — проверяем крафт, надевание, вид на пешке.

## Этап 2. Роль «На смене»
- `CompParamedicGear` на каждой вещи; при надевании/снятии пересчёт комплекта → хедиффы
  «На смене» / «Экипирован» / «Полная выкладка» (стадии с `statOffsets`/`capMods`), масштаб по качеству.
- Штрафы к стрельбе и ближнему бою, запрет работ «казнь/органы».
- Записи (Records): время на смене, «давал клятву».

## Этап 3. Клятва
- Harmony: момент смерти/увечья человека → кто инстигатор → наш ли парамедик → какая атака.
- `ThoughtDef`: «Нарушил клятву» (2 стадии: убийство/увечье), «Тяжесть на совести», «Не спас», «Вероломство».
- «Кризис веры»: счётчик нарушений, снятие ядра, запрет надевать 1 день.

## Этап 4. Способности
- «Полевая стабилизация» (`AbilityDef` + `CompAbilityEffect`, хедифф «Давящая повязка»).
- «Медик! Не стрелять!» — самое сложное: Harmony на выбор цели у врагов (валидатор цели) + сброс
  текущих целей; шанс уважения по фракциям, слом при атаке, «Вероломство».
- «Адреналин» + предмет «Шприц адреналина».
- Перезарядки с учётом комплекта и званий.

## Этап 5. Карман-аптечка
- Хранилище на 3 медикамента в жилете, авто-пополнение со склада, использование при лечении в поле.
- Если упрёмся в ограничения игры — поясная «Полевая аптечка».

## Этап 6. Прогрессия и прочее
- «Спасённые жизни», 5 званий, «Выгорание».
- «Гуманитарная помощь» (отношения с фракцией), «Меня лечил парамедик», «Сортировка» в окне спасения.

## Этап 7. Полировка
- Настройки мода (сила дебафов, длительности, шансы крика, вкл/выкл подсистем).
- Перевод EN + RU всех Defs и строк кода.
- Совместимость: Ideology/Biotech/Anomaly через `MayRequire`; Combat Extended — позже, не в v1.

## Графика
Рисую сам (Python + Pillow), проверяю глазами, правлю. Объём:
- 8 вещей × (иконка + на теле 3 направления; торсовые — × 5 типов тел) ≈ 70–90 PNG.
- Иконки способностей (4), шприц, хедиффы/звания.
Стиль — ванильный: толстая тёмная обводка, плоская заливка, лёгкая тень. Сначала делаю жилет + берет,
показываю вам, после одобрения — остальное в том же стиле.

## Звуки
Только ванильные `SoundDef` игры: крик «Не стрелять!», стабилизация (перевязка), укол.

## Порядок сдачи
Этап 0–1 → показываю спрайты жилета/берета → этап 2–3 → тест → 4–6 → 7. Коммиты по этапам, пуш — по просьбе
(remote ещё не создан).
